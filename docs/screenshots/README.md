# Screenshots

The images referenced from the root `README.md` do not exist yet. To create
them, run the application on a Windows machine and capture these four views at
a window size of roughly 1240 × 860:

| Filename | What to capture |
| --- | --- |
| `app-restore.png` | The Restore page with a video loaded, showing source details, settings and the stat cards mid-run. |
| `app-environment.png` | The Environment page with all readiness rows green. |
| `app-activity.png` | The Activity log during a run, showing progress output. |
| `website-home.png` | The website hero section at a desktop width. |

Please redact any private file paths before committing. PNG, and ideally under
500 KB each.
